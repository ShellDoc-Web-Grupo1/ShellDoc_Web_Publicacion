1. Comando pwd

Muestra el directorio actual.

Comando:

$ pwd

2. Comando whoami

Muestra el usuario actual.

Comando:

$ whoami

Resultado:

Muestra la fecha y hora.

Comando:

$ date

Comando:

$ ls

Resultado:
